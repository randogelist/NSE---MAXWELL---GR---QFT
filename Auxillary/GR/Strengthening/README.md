## File contract

Endpoint directories retain the indexed `E01`–`E18` proof stages under
`B <-> GR/Strengthening/Endpoints/`.

| File | Exact role |
|---|---|
| `Source.lean` | Complete byte-identical defining module, including imports, namespaces, ambient variables, attributes, definitions, and proof bodies. |
| `Endpoint.lean` | Canonical module import followed by `#check @QualifiedName` and `#print axioms QualifiedName`. |
| `ToDerive/*/.gitkeep` | Reserved construction; no Lean implementation supplied. |

`Source.lean` is an archival source copy. The import in `Endpoint.lean`
resolves the canonical module and its dependencies in the selected source
cohort. The entrypoint introduces no replacement theorem or altered premises.
Full defining modules preserve section context and generated declarations,
including `Summable.tsum_prod` generated by `to_additive`.

## Source verification

```bash
python3 Auxillary/GR/Strengthening/verify_collection.py
```

The verifier checks source and entrypoint bytes, exact import/query symbols,
canonical-source identity where present, directory coverage, and all 24
pending placeholders. It performs no Lean, Lake, elan, or compiler execution.

theorem-level axiom audits for promotion. The approved foundational axioms
