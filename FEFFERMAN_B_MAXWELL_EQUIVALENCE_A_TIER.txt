1. EXACT ROOT PROPOSITION

  NSEMaxwell.Classical.ExactEquivalence
  := forall nu : Real, 0 < nu -> forall c : Real, 0 < c ->
       (FeffermanB nu <-> MaxwellB nu c).

  FeffermanB nu
  := forall a : Field, Data a ->
       exists u : Velocity, exists p : Pressure, NSSolution nu a u p.

  MaxwellB nu c
  := forall m : Vec, forall B0 : Field, MagneticData B0 ->
       exists B E : Velocity, exists rho : Pressure, exists J : Velocity,
         MaxwellSolution nu c m B0 B E rho J.

2. CONCRETE SEMANTICS

  Vec = EuclideanSpace Real (Fin 3).
  Field = Vec -> Vec; Velocity = Real -> Field.
  Pressure = Real -> Vec -> Real.
  Spatial domain = unit-periodic lifts on Vec.
  Time domain = [0,infinity), including t = 0.
  Joint smoothness = ContDiffOn Real infinity on forward spacetime.
  Initial smoothness = ContDiff Real infinity.
  Spatial derivatives = actual Mathlib fderiv.
  Time derivatives = actual Mathlib derivWithin on Ici 0.
  Means = actual Lebesgue integrals over the unit cube.
  Initial velocity mean = arbitrary; forcing = zero.
  Pressure = periodic; spatial-constant time-dependent gauge unrestricted.

  Lf(x) = sum_{k in Z^3} lambda(k)
            integral_[0,1]^3 cos(2*pi*k dot (x-y)) f(y) dy,
  lambda(0)=0; lambda(k)=(4*pi^2*|k|^2)^(-1) for k != 0.
  K = curl L.
  U_m[B] = m + K B.
  G_nu,m[B] = B cross U_m[B] + nu curl B.
  V_nu,m[B] = -curl G_nu,m[B].
  Q_nu,m[B] = div G_nu,m[B].
  DG_nu,m[B](h) = h cross U_m[B] + B cross K h + nu curl h.
  J_nu,c,m[B] = c^2 curl B - DG_nu,m[B](V_nu,m[B]).
  pB = L Q[B] - |U_m[B]|^2/2 + mean(|U_m[B]|^2)/2.

  MaxwellSolution imposes div B=0, B_t+curl E=0, div E=rho,
  E_t-c^2 curl B=-J, E=G[B], rho=Q[B], J=J[B], initial B=B0,
  zero spatial mean of B, and the stated smoothness/periodicity of all fields.

  The Fourier formulas are total definitions. Their convergence, inversion,
  regularity, and time commutation still require the explicit analytic laws.

4. EXACT REMAINING ANALYTIC PREMISE REGISTER

  Nine fields remain. All nine are OPEN as concrete analytic theorems.
  They are theorem hypotheses, not new Lean axiom declarations.
  Names below are in NSEMaxwell.Bridge, with Classical and Constitutive open.
  MagneticPath means joint smoothness, periodicity, zero divergence and mean.
  CanonicalRegularity records smoothness/periodicity of the displayed canonical
  velocity, pressure, E, rho and J, and divergence-free canonical velocity.

structure PeriodicAnalyticLaws : Prop where
  reconstruct_velocity : ∀ (a : Field), Data a →
    U (spatialMean a) (spatialCurl a) = a
  reconstruct_curl : ∀ (m : Vec) (B : Field), MagneticData B →
    spatialCurl (U m B) = B
  vorticity_regularity : ∀ (u : Velocity),
    SmoothVelocity u → PeriodicVelocity u →
    (∀ t : ℝ, 0 ≤ t → ∀ x : Vec, NSEMaxwell.Classical.divergence (u t) x = 0) →
    MagneticPath (curlTrajectory u)
  canonical_regularity : ∀ (ν c : ℝ) (m : Vec) (B : Velocity),
    MagneticPath B → CanonicalRegularity ν c m B
  mean_conservation : ∀ (ν : ℝ) (u : Velocity) (p : Pressure),
    SmoothVelocity u → SmoothPressure p →
    PeriodicVelocity u → PeriodicPressure p →
    (∀ t : ℝ, 0 ≤ t → ∀ x : Vec, NSEMaxwell.Classical.divergence (u t) x = 0) →
    (∀ t : ℝ, 0 ≤ t → momentumResidual ν u p t = 0) →
    ∀ t : ℝ, 0 ≤ t → spatialMean (u t) = spatialMean (u 0)
  vorticity_residual : ∀ (ν : ℝ) (u : Velocity) (p : Pressure),
    SmoothVelocity u → SmoothPressure p →
    PeriodicVelocity u → PeriodicPressure p →
    (∀ t : ℝ, 0 ≤ t → ∀ x : Vec, NSEMaxwell.Classical.divergence (u t) x = 0) →
    ∀ t : ℝ, 0 ≤ t →
    spatialCurl (momentumResidual ν u p t) =
      timeDerivative (curlTrajectory u) t +
        spatialCurl (fun x => cross (spatialCurl (u t) x) (u t x) +
          ν • spatialCurl (spatialCurl (u t)) x)
  reconstruction_time : ∀ (m : Vec) (B : Velocity), MagneticPath B →
    ∀ t : ℝ, 0 ≤ t →
    timeDerivative (canonicalVelocity m B) t = K (timeDerivative B t)
  electric_hodge : ∀ (ν : ℝ) (m : Vec) (B : Field), MagneticData B →
    G ν m B + NSEMaxwell.Classical.gradient (headPotential ν m B) = K (spatialCurl (G ν m B))
  electric_time_chain : ∀ (ν : ℝ) (m : Vec) (B : Velocity), MagneticPath B →
    ∀ t : ℝ, 0 ≤ t →
    timeDerivative (canonicalElectric ν m B) t =
      DG ν m (B t) (timeDerivative B t)

7. DETERMINISTIC ROOT PROOF

  A. Momentum split, from the nine explicit endpoints and concrete calculus:

    R_N(U_m[B],pB) = K(B_t) + K(curl G[B]).

  B. Faraday cancellation:

    R_F=0 -> B_t=-curl G[B]
          -> R_N=-K(curl G[B])+K(curl G[B])=0.

  C. Induced-current Ampere cancellation:

    R_F=0 -> B_t=V[B]
          -> E_t=DG[B](V[B])
          -> E_t-c^2 curl B+J[B]=0.

  D. Forward solution construction:

    a=U_m[B0], NSSolution(nu,a,u,p)
      -> conservation of mean and Hodge reconstruction
      -> B=curl u, E=G[B], rho=Q[B], J=J[B]
      -> exact MaxwellSolution with B(0)=B0.

  E. Reverse solution construction:

    exact MaxwellSolution(nu,c,m,B0,B,E,rho,J)
      -> canonical Faraday equation
      -> u=U_m[B], p=pB
      -> exact NSSolution with u(0)=U_m[B0].

  F. Universal data transport:

    a <-> (mean a,curl a)
    (m,B0) <-> U_m[B0]
    -> FeffermanB nu <-> MaxwellB nu c
    -> positive-nu, positive-c selected quantifier prefix.

  The analytic premise register contains no FB/MB proposition and no global
  solution-existence implication. Every existence implication is derived.
