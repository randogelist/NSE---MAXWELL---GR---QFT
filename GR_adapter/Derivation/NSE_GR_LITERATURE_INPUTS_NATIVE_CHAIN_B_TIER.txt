CK01. EQUIVALENT NORMS / TAXICAB DOMAIN.
Endpoints: ML-CK-01, ML-CK-02, ML-CK-11, ML-CK-25.
Put Z=R (+)_1 E, with ||(T,X)||=|T|+||X||, and
H=(R (+)_1 E) (+)_1 (F (+)_1 L(E,F)). Here (+)_1 denotes WithLp 1
of the parenthesized product. The identity maps between
these products and the ordinary products are continuous linear equivalences.
Compose a power series with these equivalences and use the multilinear
composition bound. Analyticity, eventual equality, and Frechet derivatives
transport through the equivalences; hence the target Euclidean norms are
unchanged semantically. Write e=(1,0), iX(x)=(0,x).

CK02. SYMMETRIC COEFFICIENT REPRESENTATIVES.
Endpoints: ML-CK-04, ML-CK-05, ML-CK-06, ML-CK-07, ML-CK-22.
For a continuous d-linear coefficient a, define

  Sym(a)(z1,...,zd) = (1/d!) sum_{sigma in S_d} a(z_sigma(1),...,z_sigma(d)).

The d=0 convention is 0!=1 and a singleton permutation set. Then
Sym(a)(z,...,z)=a(z,...,z), ||Sym(a)||<=||a||, and Sym(a) is symmetric.
The bound follows by the triangle inequality and the operator-norm estimate
for each summand. Thus every analytic germ has a symmetric coefficient
expansion with the same diagonal sum and at least the same convergence radius.
For a symmetric expansion q, its d-th derivative at the centre is d! q_d
by ML-CK-22. Consequently symmetric coefficients are unique.

CK03. BANACH COEFFICIENT SPACE.
Endpoints: ML-CK-03, ML-CK-23.
For a Banach space G define

  S_d(Z,G) = {a : Z^d ->L_mult[R] G | a invariant under all slot permutations},
  B0(Z,G) = {(a_d)_{d>=1} : a_d in S_d(Z,G), sum_d ||a_d|| < infinity},
  ||a||_B = sum_{d>=1} ||a_d||;     a_0 := 0.

S_d is the intersection of the kernels a -> a-a.domDomCongr(sigma),
each a continuous linear map. It is closed in the complete continuous
multilinear-map space. Hence each S_d is complete. B0 is the dependent
lp space with p=1 on d>=1 and these fibres. It is complete by ML-CK-03.
Equivalently, a Cauchy sequence converges coefficientwise and the tail
estimate for its l1 norm proves norm convergence. Its closed unit ball
Q={a: ||a||_B<=1} is complete and contains 0, by ML-CK-23.

CK04. EVALUATION / ANALYTIC SEMANTICS.
Endpoints: ML-CK-05, ML-CK-07, ML-CK-08, ML-CK-09, ML-CK-15,
ML-CK-16, ML-CK-22, ML-CK-24.
For a in B0 define Ev(a)(z)=sum_{d>=1}a_d(z,...,z) when ||z||<1.
Each term has norm <=||a_d|| ||z||^d. The same formula converges for
||z||<=1, with ||Ev(a)(z)||<=||a||_B. Hence the formal-series radius is
>=1; ML-CK-08/09/24 give analyticity throughout the open unit ball.
On a smaller closed ball of radius 0<r<1, k-th derivatives are dominated by
sum_{d>=k} (d!/(d-k)!) ||a_d|| r^(d-k), which is finite because
sup_{d>=k}(d!/(d-k)!) r^(d-k)<infinity and sum_d||a_d||<infinity.
Thus differentiation and summation commute there, also by the power-series
derivative API. If Ev(a)=Ev(b) near 0 then a=b by CK02.
Evaluation is linear and bounded; these statements concern actual sums,
not formal series alone.

CK05. MULTILINEAR SUPERPOSITION ON COEFFICIENT SPACES.
Endpoints: ML-CK-04, ML-CK-05, ML-CK-06.
Let c:H^j ->L_mult G be symmetric, j>=1. For W1,...,Wj in B0(Z,H),
define a symmetric coefficient of total degree d by

  T_c(W1,...,Wj)_d
    = sum_{k1+...+kj=d; all ki>=1}
        Sym( c( W1_k1(-), ..., Wj_kj(-) ) ).

The arguments of the inner multilinear map are partitioned into consecutive
blocks of lengths k1,...,kj before symmetrization. There are finitely many
such compositions for each d. Its norm is at most

  ||c|| sum_{k1+...+kj=d} product_i ||Wi_ki||.

Summing nonnegative terms over d gives the product of j l1 sums; therefore

  ||T_c(W1,...,Wj)||_B <= ||c|| product_i ||Wi||_B.                 (CK05.1)

The defining map is j-linear, continuous, and symmetric in the W arguments.
Absolute convergence allows evaluation and all summations to be reordered:

  Ev(T_c(W1,...,Wj))(z)=c(Ev(W1)(z),...,Ev(Wj)(z)).              (CK05.2)

CK06. TIME PRIMITIVE WITH A UNIFORM COEFFICIENT NORM.
Endpoints: ML-CK-04, ML-CK-05.
For a in B0(Z,F), define A(a)_0=A(a)_1=0. For d>=1 and N=d+1,
z_i=(T_i,X_i), set

  A(a)_N(z_1,...,z_N)
    = (1/N) sum_{nonempty S subset {1,...,N}}
        (product_{i in S} T_i)
        a_d(e repeated |S|-1, iX(X_j) for j notin S).

Symmetry of a_d removes ordering dependence. This is symmetric N-linear.
Expanding product_i (|T_i|+||X_i||) and omitting the nonnegative S=empty
term yields

  ||A(a)_N(z_1,...,z_N)||
    <= ||a_d||/N product_i (|T_i|+||X_i||),
  ||A(a)_N|| <= ||a_d||/(d+1),
  ||A(a)||_B <= (1/2)||a||_B.                                  (CK06.1)

Hence A is a bounded linear map B0(Z,F)->B0(Z,F). On the diagonal,

  A(a)_{d+1}(T,X)^(d+1)
   = sum_{k=1}^{d+1} binom(d+1,k)/(d+1)
       T^k a_d(e^(k-1),iX(X)^(d+1-k)).

Since binom(d+1,k)/(d+1)=binom(d,k-1)/k, this is exactly the
time primitive, with zero initial trace, of a_d((T,X)^d).

CK07. SPATIAL DERIVATIVE OF THE TIME PRIMITIVE.
Endpoints: ML-CK-04, ML-CK-05.
For d>=1, define B(a)_d as a symmetric d-linear map with values in L(E,F):

  [B(a)_d(z_1,...,z_d)]h
   = sum_{nonempty S subset {1,...,d}}
       (product_{i in S}T_i)
       a_d(e repeated |S|-1, iX(X_j) for j notin S, iX(h)).

The same subset-product expansion gives

  ||[B(a)_d(z_1,...,z_d)]h||
     <=||a_d|| ||h|| product_i (|T_i|+||X_i||),
  ||B(a)_d||<=||a_d||,
  ||B(a)||_B<=||a||_B.                                        (CK07.1)

Thus B:B0(Z,F)->B0(Z,L(E,F)) is bounded linear. On repeated arguments,
the coefficient of T^k is binom(d,k). Differentiating the CK06 expression
in X gives precisely this coefficient, because
((d+1-k)/(d+1))*binom(d+1,k)=binom(d,k). Therefore B=D_X A.
No boundedness of the standalone operator D_X on B0 is asserted or used.

CK08. OPERATOR/EVALUATION IDENTITIES.
Endpoints: ML-CK-15, ML-CK-16.
CK04 justifies termwise differentiation on every smaller ball. CK06/07 give

  Ev(Aa)(0,X)=0,
  partial_T Ev(Aa)(T,X)=Ev(a)(T,X),
  D_X Ev(Aa)(T,X)=Ev(Ba)(T,X).                                 (CK08.1)

These identities hold on the entire open taxicab unit ball. Conversely,
an analytic w with w(0,X)=0 and partial_T w=Ev(a) satisfies w=Ev(Aa)
on a smaller ball: for each X, subtract the two functions and integrate
its zero T-derivative along the segment from 0 to T. The segment remains
in the taxicab ball. Equivalently, compare the T-polynomial coefficients.

GJ03 | Coordinate curvature symmetries and contracted Bianchi
------------------------------------------------------------
This step proves the needed identity from coordinate derivatives. It does
not assume Bianchi as a literature field. Let g be any analytic symmetric
nondegenerate coordinate metric (in particular the constructed Gaussian g).
Define
  R^a_bcd = partial_c Gamma^a_db - partial_d Gamma^a_cb
             + Gamma^a_ce Gamma^e_db - Gamma^a_de Gamma^e_cb,
  R_abcd = g_ae R^e_bcd,
  Ric_bd = g^{ac} R_abcd.
Expanding the latter contraction gives the exact NSEGR.ricci convention.

(i) Christoffel substitution gives
  Gamma^a_bc=Gamma^a_cb,
  partial_c g_ab = g_eb Gamma^e_ca + g_ae Gamma^e_cb.       (GJ03.1)
The second equation is metric compatibility; multiplying by g^{-1} also
gives partial_c g^{ab}=-Gamma^a_ce g^{eb}-Gamma^b_ce g^{ae}.
These are obtained by distributing the three Christoffel summands and
cancelling the crossed partial derivatives, using g_ab=g_ba.

(ii) R_abcd=-R_abdc directly. Expand
  R^a_bcd + R^a_cdb + R^a_dbc.
The six derivative terms cancel in pairs by the lower-index symmetry of
Gamma; the six quadratic terms cancel after swapping their finite dummy
indices. Thus the first Bianchi identity holds.

(iii) For a covariant tensor T define
  (nabla_c T)_ab=partial_c T_ab-Gamma^e_ca T_eb-Gamma^e_cb T_ae.
Expanding the commutator on g and using commuting second partials gives
  ([nabla_c,nabla_d]g)_ab
    = -R^e_acd g_eb - R^e_bcd g_ae.
The left side is zero by (i), hence R_abcd=-R_bacd.
Let B(a;b,c,d)=R_abcd+R_acdb+R_adbc. All B vanish by (ii).
Using the two antisymmetries,
  2(R_abcd-R_cdab)
   = B(a;b,c,d)-B(b;a,c,d)-B(c;d,a,b)+B(d;c,a,b)=0.
Therefore R_abcd=R_cdab. Contracting this pair symmetry shows Ric_ab=Ric_ba.

(iv) Define connection matrices (Gamma_c)^a_b=Gamma^a_cb and
  R_cd=partial_c Gamma_d-partial_d Gamma_c+[Gamma_c,Gamma_d].
The cyclic sum of the endomorphism-valued covariant derivative is zero:
  sum_cyclic(e,c,d)(partial_e R_cd+[Gamma_e,R_cd])=0.     (GJ03.2)
Expansion is a complete cancellation by degree:
  degree 1: partial_e partial_c Gamma_d terms cancel by mixed-partial
            commutation;
  degree 2: partial_e[Gamma_c,Gamma_d]
            =[partial_e Gamma_c,Gamma_d]+[Gamma_c,partial_e Gamma_d]
            cancels the commutators with partial_c Gamma_d-partial_d Gamma_c;
  degree 3: [Gamma_e,[Gamma_c,Gamma_d]]+cyclic=0,
            by associativity (each of the six triple products occurs twice
            with opposite signs).
The corrections for the form indices c,d cancel cyclically because
Gamma^a_bc=Gamma^a_cb. Lowering the first index commutes with nabla by (i).
Thus
  nabla_e R_abcd+nabla_c R_abde+nabla_d R_abec=0.         (GJ03.3)

(v) Contract (GJ03.3) with g^{ac}; using the last-index antisymmetry gives
  nabla^a R_abde = nabla_d Ric_be-nabla_e Ric_bd.
Contract again with g^{bd}. Since g^{bd}R_abde=-Ric_ae,
  -nabla^a Ric_ae = nabla^b Ric_be-partial_e R(g).
Therefore
  2 nabla^a Ric_ab=partial_b R(g),
  nabla^a (Ric_ab-(1/2)R(g)g_ab)=0.                     (GJ03.4)

All derivatives exist and commute by AnalyticAt.fderiv, AnalyticAt.contDiffAt
and ContDiffAt.isSymmSndFDerivAt. Products and finite sums use the actual
Frechet product/chain rules. This is a finite coordinate proof; no metric
signature restriction, manifold construction, or covariant-derivative
black box is added.

    =((2*pi*i*k_j)*m_w(k))*c_f(k)
    =m_(j::w)(k)*c_f(k).
This proves exactly the List recursion of LiteraturePartialWord, including
repeated indices and the coefficient signs. Smooth mixed-partial symmetry
is compatible with this identity but not needed for this induction.

Proposed native endpoint:
  NSEGR.literatureFourierCoefficient_partialWord.

FT07 — PRODUCT-WEIGHT DECAY WITHOUT DIMENSION-DEPENDENT SHELL ESTIMATES
Dependencies: FT01, FT02, FT05. Selected endpoint: ML-FT-10.

For a smooth periodic g:E_n->C define
  A_j g := g - (2*pi)^(-2)*D_j(D_j g),
  L_n g := A_0(A_1(...(A_(n-1) g)...)),
  C_n(g) := integral_{Q_n} |L_n g(x)| dx,
  B_n(k) := product_j (1+(k_j:R)^2)^(-1).

L_n uses one fixed finite coordinate order. Each intermediate function is
smooth and periodic by FT02. Consequently C_n(g) is finite and nonnegative.
FT05 applied twice gives
  c_(D_j^2 g)(k)=-(2*pi)^2*k_j^2*c_g(k),
and hence
  c_(A_j g)(k)=(1+k_j^2)*c_g(k).
Induction through the finite composition gives
  c_(L_n g)(k)=(product_j (1+k_j^2))*c_g(k).
ML-FT-10 and FT01 show
  |c_(L_n g)(k)|
    <= integral_{Q_n} |L_n g(x)*chi_{-k}(x)| dx
    = C_n(g).
Each factor 1+k_j^2 is strictly positive, so division gives the exact bound
  |c_g(k)| <= C_n(g)*B_n(k).                                  [FT07.1]

This includes k=0; no inverse of k_j at zero occurs. The normalization
(2*pi)^(-2) is defined because pi>0. No estimate uniform in n or uniform in
g is required or claimed. The finite operator has differential order 2n.

Proposed native endpoint:
  NSEGR.literatureFourierCoefficient_product_decay.

FT08 — SUMMABILITY OF THE PRODUCT WEIGHT
Selected endpoints: ML-FT-11, ML-FT-12.

Set b(l)=(1+(l:R)^2)^(-1), l in Z. Then
  0<=b(l)<=1_{l=0}+1/(l:R)^2.
At l=0 the right side is 1 because 1/0=0 in the field convention; at
l!=0 the bound follows from 0<l^2<=1+l^2. The singleton indicator is
summable, and ML-FT-11 at p=2 proves summability of the second term.
Comparison therefore proves sum_l b(l)<infinity.

For n=0 the index set Fin0->Z is a singleton and B_0=1. Given summability
of B_n, identify (Fin(n+1)->Z) with Z times (Fin n->Z). Under this bijection
B_(n+1)(l,k)=b(l)*B_n(k). Both factors are nonnegative and summable, so
ML-FT-12 proves summability at n+1. Induction gives
  Summable(B_n), for every finite n.
Equivalently sum_k B_n(k)=(sum_l b(l))^n; this identity is optional,
whereas summability alone is sufficient for FT09.

Proposed native endpoint:
  NSEGR.literatureProductWeight_summable.

FT10 — ACTUAL POINTWISE RECONSTRUCTION
Dependencies: FT02, FT04, FT06, FT09.
Selected endpoints: ML-FT-13, ML-FT-14.

abbrev LiteratureFrequency (n : ℕ) := Fin n → ℤ

def LiteratureUnitVector {n : ℕ} (i : Fin n) : LiteratureSpace n :=
  EuclideanSpace.single i (1 : ℝ)

def LiteratureUnitCube (n : ℕ) : Set (LiteratureSpace n) :=
  {x | ∀ i : Fin n, 0 ≤ x i ∧ x i ≤ 1}

def LiteraturePeriodic {n : ℕ} (f : LiteratureSpace n → ℂ) : Prop :=
  ∀ (x : LiteratureSpace n) (i : Fin n), f (x + LiteratureUnitVector i) = f x

/-- The actual unit-period character; no Fourier data are supplied abstractly. -/
def LiteratureCharacter {n : ℕ} (k : LiteratureFrequency n)
    (x : LiteratureSpace n) : ℂ :=
  Complex.exp ((2 * (Real.pi : ℂ) * Complex.I) *
    ((∑ i : Fin n, (k i : ℝ) * x i : ℝ) : ℂ))

def LiteratureFourierCoefficient {n : ℕ} (f : LiteratureSpace n → ℂ)
    (k : LiteratureFrequency n) : ℂ :=
  ∫ x in LiteratureUnitCube n, f x * LiteratureCharacter (-k) x

/-- A finite coordinate derivative word, expressed using actual Frechet
derivatives. Smoothness identifies these with the usual multiindex partials. -/
def LiteraturePartialWord {n : ℕ} :
    List (Fin n) → (LiteratureSpace n → ℂ) → LiteratureSpace n → ℂ
  | [], f => f
  | i :: w, f => fun x =>
      fderiv ℝ (LiteraturePartialWord w f) x (LiteratureUnitVector i)

def LiteratureFourierWordMultiplier {n : ℕ} (w : List (Fin n))
    (k : LiteratureFrequency n) : ℂ :=
  (w.map (fun i => 2 * (Real.pi : ℂ) * Complex.I * (k i : ℂ))).prod

/-- LI03. Smooth periodic Fourier inversion, derivative multipliers, absolute
coefficient summability, and uniform differentiated convergence. The native
Poisson/Leray identities and time-analytic estimates are not input fields. -/
structure LiteratureSmoothFourierInput : Prop where
  reconstruct : ∀ (n : ℕ), 0 < n → ∀ (f : LiteratureSpace n → ℂ),
    ContDiff ℝ ∞ f → LiteraturePeriodic f → ∀ w : List (Fin n),
      (∀ k : LiteratureFrequency n,
        LiteratureFourierCoefficient (LiteraturePartialWord w f) k =
          LiteratureFourierWordMultiplier w k * LiteratureFourierCoefficient f k) ∧
      Summable (fun k : LiteratureFrequency n =>
        ‖LiteratureFourierWordMultiplier w k * LiteratureFourierCoefficient f k‖) ∧
      HasSumUniformly

          (LiteratureFourierWordMultiplier w k * LiteratureFourierCoefficient f k) *
            LiteratureCharacter k x)
        (LiteraturePartialWord w f)
