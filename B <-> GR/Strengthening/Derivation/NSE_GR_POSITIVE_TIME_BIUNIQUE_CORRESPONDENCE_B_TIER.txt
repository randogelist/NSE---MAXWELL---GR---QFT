0. PARAMETER AND VARIABLE CONVENTIONS
-------------------------------------

Fix

  nu,rho : Real,
  hnu : 0 < nu,
  hrho : rho != 0,
  a0 : Field,
  ha0 : NSEMaxwell.Classical.Data a0.

The initial datum is always denoted a0.

Source elements are denoted

  s,r : AnalyticForwardTrajectory nu a0.

Target elements are denoted

Thus the phrase

  "for every a in the first input there exists one unique a' in the second"

  forall s, exists! gamma, s ~ gamma.

The converse totality and uniqueness statement is

  forall gamma, exists! s, s ~ gamma.


1. EXACT SOURCE CARRIER
-----------------------

The repository source carrier is

  NormalizedForwardTrajectory nu a0.

It is the quotient of normalized smooth forward NSE representatives by
equality on all t >= 0. It retains no unconstrained negative-time data.
Its pressure satisfies q(t,0)=0, and its underlying totalized pair satisfies
the exact repository NSSolution predicate.

Define the analytic source subtype

  AnalyticForwardTrajectory nu a0
    :=
  { s : NormalizedForwardTrajectory nu a0 //
      AnalyticOnNhd Real
        (fun z : Real x Vec => s.totalVelocity z.1 z.2)
        positiveSpacetime }.

Equivalently,

  s in AnalyticForwardTrajectory nu a0

means:

  (S1) s is a normalized smooth forward NSE trajectory;
  (S2) its initial velocity is a0;
  (S3) its velocity is jointly real analytic on
         (0,infinity) x T3;
  (S4) no analyticity is required at t=0.

The normalized pressure is not added as a carrier premise. Existing pressure
identification and analytic Poisson reconstruction give

  velocity analytic on positiveSpacetime
    =>
  normalized pressure analytic on positiveSpacetime.

Hence each analytic source element defines an actual positive analytic NSE
pair and therefore an actual NSE germ at every positive center.

  forall s : AnalyticForwardTrajectory nu a0,

L3. Native geometric encoding.

  coherentFamilyEquiv nu rho hrho a0 eta_s.

The existing coherent-family theorem transfers both local coherence and the

  eta_s

  (nativeLocalEquiv ...).symm (gamma_s.val tau)

  sourceGerm(s,tau).

Therefore

  s ~ gamma_s.


6. RIGHT UNIQUENESS: THE MATCHED GR FAMILY IS UNIQUE
----------------------------------------------------

THEOREM R-UNIQUE:

  forall s gamma zeta,
    s ~ gamma ->
    s ~ zeta ->
    gamma = zeta.

DERIVATION.

Assume hgamma : s ~ gamma and hzeta : s ~ zeta.
For each tau,

  D_tau(gamma_tau)
    =
  sourceGerm(s,tau)
    =
  D_tau(zeta_tau),

where

  D_tau := (nativeLocalEquiv nu rho tau.val hrho).symm.

Because D_tau is an equivalence, it is injective. Hence

  gamma.val tau = zeta.val tau.

Function extensionality and grForwardFamily_ext yield

  gamma = zeta.

Combining Sections 5 and 6:

    exists! gamma : GRForwardFamily nu rho a0,
      s ~ gamma.

  Psi(Phi(s)) = s,
