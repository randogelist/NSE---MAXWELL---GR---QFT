1. EXACT NATIVE OBJECTS
----------------------

Namespace retained: NSEMaxwell.Classical.
Project module root: MaxwellEndpoint.

Vec := EuclideanSpace R (Fin 3).
Field := Vec -> Vec.
ScalarField := Vec -> R.
Velocity := R -> Field.
Pressure := R -> ScalarField.
Frequency := Fin 3 -> Z.

Q := {x : Vec | forall i, 0 <= x_i and x_i <= 1}.
spatialMean(a) := integral_Q a(x) dx.
scalarMean(f) := integral_Q f(x) dx.

coordinateDerivative(a,i,x) := fderiv R a x (unitVector i).
div, grad, curl, Laplacian and cross product retain their exact coordinate
formulas. timeDerivative uses derivWithin on Ici(0).

SmoothVelocity(u) :=
  ContDiffOn R infinity ((t,x) |-> u(t,x)) {(t,x) | 0 <= t}.
SmoothPressure has the identical joint smoothness domain and order.
SpatialPeriodic(f) := forall x,i, f(x + unitVector i) = f(x).

Data(a) := smooth(a) and periodic(a) and div(a)=0.
MagneticData(B0) := Data(B0) and spatialMean(B0)=0.
The velocity mean m is arbitrary.

2. FROZEN FOURIER AND CONSTITUTIVE DEFINITIONS
--------------------------------------------

lambda(0) := 0.
lambda(k) := (4*pi^2*sum_i k_i^2)^(-1), k != 0.
C_k(x,y) := cos(2*pi*sum_i k_i*(x_i-y_i)).

vectorL(a)(x) := tsum_k lambda(k) * integral_Q C_k(x,y) * a(y) dy.
scalarL(f)(x) := tsum_k lambda(k) * integral_Q C_k(x,y) * f(y) dy.

K(B) := curl(vectorL(B)).
U_m[B] := m + K(B).
G_nu,m[B] := B cross U_m[B] + nu*curl(B).
V_nu,m[B] := -curl(G_nu,m[B]).
Q_nu,m[B] := div(G_nu,m[B]).
DG_nu,m[B](h) := h cross U_m[B] + B cross K(h) + nu*curl(h).
J_nu,c,m[B] := c^2*curl(B) - DG_nu,m[B](V_nu,m[B]).

Canonical velocity, electric, charge, current and pressure trajectories retain
the original definition bodies. The canonical pressure is
  scalarL(Q[B]) - |U_m[B]|^2/2 + scalarMean(|U_m[B]|^2)/2.

All expressions are actual Lean definitions over Mathlib derivatives,
Lebesgue integrals and infinite sums. Total definability does not prove
convergence, Poisson identities, Hodge inversion or smooth parameter dependence.

3. EXACT MAXWELL SOLUTION PREDICATE
---------------------------------

MaxwellSolution(nu,c,m,B0,B,E,rho,J) consists of:

  SmoothVelocity(B), SmoothVelocity(E), SmoothPressure(rho), SmoothVelocity(J);
  periodicity of B,E,rho,J for every t >= 0;
  spatialMean(B(t)) = 0 for every t >= 0;
  div(B(t))(x) = 0;
  timeDerivative(B)(t,x) + curl(E(t))(x) = 0;
  div(E(t))(x) = rho(t,x);
  timeDerivative(E)(t,x) - c^2*curl(B(t))(x) = -J(t,x);
  E(t) = G_nu,m[B(t)];
  rho(t) = Q_nu,m[B(t)];
  J(t) = J_nu,c,m[B(t)];
  B(0) = B0.

Every differential equation above is quantified over all t >= 0 and all x.
The original structure field order and definition body are preserved.

Exact proposition:

  MaxwellB(nu,c) :=
    forall m : Vec, forall B0 : Field,
    MagneticData(B0) ->
      exists B E : Velocity, exists rho : Pressure, exists J : Velocity,
        MaxwellSolution(nu,c,m,B0,B,E,rho,J).

This proposition is defined for every real nu,c. The equivalence root retains
its existing restrictions nu > 0 and c > 0.
